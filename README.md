# Reign of Victory

This project is a landing page for the Reign of Victory video game. Page provides in-game visuals, artwork, links to social media and a brief description of the game. Project was built with React and CSS. The site is built to be both responsive and adaptive and is viewable at a wide range of display sizes. 

## Setup

In order to start up the project install with `npm install` and then use `npm run start`.
